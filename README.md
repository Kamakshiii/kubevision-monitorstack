# KubeVision MonitorStack

A complete Kubernetes GitOps monitoring platform using:

- Kubernetes
- Helm
- ArgoCD
- GitHub Actions
- Prometheus
- Grafana

---

## Project Goals

This project helps learn:

- Kubernetes deployments
- Helm package management
- GitOps using ArgoCD
- CI/CD using GitHub Actions
- Monitoring with Prometheus
- Dashboards with Grafana

---

## Architecture

GitHub → GitHub Actions → ArgoCD → Kubernetes
